# 구현 현황 — 비고

`docs/status.md`의 **비고 열에 그대로 붙는다.** `## <도메인명>` 아래 한 줄씩 적는다.
표의 숫자는 코드에서 뽑히지만 **"왜 없는가"는 코드에 안 적혀 있어** 여기만이 출처다.

## admission
홈페이지 입학예약 수신 전용. 앱 API 가 없는 것이 정상이다.

## appconfig
온라인 질의응답 메뉴 숨김 플래그가 없다 — 0908 회신에 「숨김 제공」으로 나갔다.

## attendance
병원영수증 첨부 후 벌점 취소가 **파일 업로드 기능이 없어** 막혀 있다(0908 반영 예정).

## audit
엔티티가 `domain/audit/AuditLog` 한 개라 테이블 수집기에 안 잡힌다. 없는 게 아니다.

## chat
**미착수.** SDK 미정이라 벤더 패키지를 못 만든다. `integration/sendbird` 는 빈 폴더다.

## consult
슬롯이 날짜 단위라 **요일별 반복 등록이 없다** — 매주 같은 시간대를 날짜마다 열어야 한다.

## facility
앱 API 가 없는 것은 좌석 이탈 앱 연동이 **2차 이관**(I-16)됐기 때문이다.

## firewall
`integration/zyxel` 에 골격만 있다. **실제 장비 연동은 자격증명(E-1) 미수령**으로 대기.

## grade
엑셀 업로드 파서 **미착수**. 평가원 파일은 있고 **더프 회차 파일 실물 대기**.
2단 헤더라 `common/excel` 의 `ColumnMapping` 을 그대로 못 쓴다.

## kiosk
DSA 호환 25개 계약. 앱·관리자 API 가 없는 것이 정상이다.

## lecture
수강료가 **안내용**이라 결제가 생성되지 않는다(PG 규격 대기).
유형 마스터 작업 중. 홍보용 PDF·사진은 **파일 업로드 없어** 막혀 있다.

## meal
급식업체 **조회용 계정 미착수**(0908 반영 예정, 사용자 유형 신설).
환불 금액 계산까지만 — **실제 PG 취소 없음**.

## notification
템플릿·수신설정·토큰 등록까지 됐고 **실제 발송이 없다** — FCM/APNs(E-7)·알림톡 심사(E-5) 대기.
지금은 로그로만 남는다.

## payment
청구·환불 계산까지. **PG 연동 없음** — MID·연동규격·테스트 가맹점 미수령.
그래서 가상계좌 발급·입금 만료 처리가 돌지 않는다.

## penalty
규칙 엔진은 돌지만 **`penalty_rule.active` 가 전부 false** — 트리거→점수 매핑(I-5) 미확정.

## plan
중단일에 **입력이 막히지 않는다.** 미작성 집계에서만 빠진다(0908 결정: 막기로 함).

## qna
**오프라인 질의응답만** 있다. 온라인 미착수. 슬롯에 **과목 축이 없어** 과목별 일정을 못 만든다.

## report
집계 전용. 관리자 API 가 없는 것이 정상이다.

## routine
**회차 축이 없다.** 항목(이름·과목)까지만 등록한다 — 월간 표 반영 시 추가.

## scholarship
판정 로직은 있으나 **취소 규칙이 비활성** — 수능 기준 장학의 판정 시점 미확정.

## search
공통 검색 모듈. 도메인이 아니라 `SearchScope`·`SearchPredicates` 다.

## statistics
집계 전용이라 테이블이 없다.

## user
회원가입·인증·계정 관리. **인증번호 발송이 목업**이라 문자가 실제로 안 나간다(SMS 업체 미정).
